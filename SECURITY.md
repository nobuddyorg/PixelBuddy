# Security policy

## Supported versions

PixelBuddy is released through [GitHub Releases](https://github.com/nobuddyorg/PixelBuddy/releases). Only the
latest release receives security fixes. Please update before reporting an issue.

| Version | Supported |
|---|---|
| Latest release | Yes |
| Older releases | No |
| Unreleased `main` builds | Best effort |

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report them privately through GitHub's private vulnerability reporting:
[Report a vulnerability](https://github.com/nobuddyorg/PixelBuddy/security/advisories/new)
(repository → **Security** → **Report a vulnerability**).

Include, if you can:

- the PixelBuddy version, Android version and device model,
- what an attacker can do and the steps to reproduce,
- a proof of concept, logs or screenshots (remove any personal data first).

You will get an answer within 7 days. Once the issue is confirmed, a fix is released as soon as possible and the
advisory is published together with the release. Reporters are credited unless they ask not to be.

## Scope

In scope: the PixelBuddy app and the build, release and signing setup in this repository.

Out of scope: vulnerabilities in Android, One UI or other apps, and issues that need a rooted device or physical
access to an unlocked phone.
